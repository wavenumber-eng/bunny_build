# Log: platform-chipdata-enrichment-prototype

Moved `platform-guide` stage 3 from design-only to a compact, committed
prototype for `MCXN947`.

What changed:

- Added `isa/tools/enrich_platform.py`, which consumes a filtered nxp-monkey JSON
  mirror and writes compact public chip-data facts. The raw MCUXpresso Config
  Tools tree stays in ignored `build/` scratch or the nxp-monkey cache.
- Committed `isa/ezh_b/platform_enrichment/MCXN947.json`, not the raw tree:
  11 `SMARTDMA0` wrapper registers, 8 `SMARTDMAARCHB_INMUX` registers with 71
  enumerated input values, and 213 `SMARTDMA_PIO` pin-mux options across five
  package variants.
- Updated the platform generator/template to render chip-data enrichment only
  for enriched parts, with an enriched-parts count and search terms for
  register, inputmux, and pin-mux names.
- Updated `docs/design/platform-data-pipeline.html`: stage 3 is now incremental
  and prototyped for MCXN947; bulk enrichment across the confirmed part list
  remains the expensive follow-up.
