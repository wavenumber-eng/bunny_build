# Log: choose-doc-toolchain — ADR drafted and proved with a full-db spike

## ADR isa-adr-0002 (status: proposed — awaiting Eli's review)

Decision drafted: **custom Python generator** (Jinja2 templates +
python-markdown for the prose chapters), emitting self-contained static HTML
to `docs/html/` with inline-SVG bitfield diagrams derived from the slice
data, deterministic output, and a `--check` mode that makes doc drift a CI
failure like encoding drift. Rejected: MkDocs Material (we would write the
same db-walking generator and then feed a second generator through plugin
glue; heavy deps; CDN-default assets), Sphinx (custom domain/extension for
TOML content, and bunny_build's public API is C), Doxygen (wrong shape),
hand-written pages (violates isa-adr-0001 on principle).

## Spike: isa/tools/gen_docs_spike.py (stdlib-only, committed)

Proves the pipeline end-to-end over the real db — not a mockup:

- 25 opcode pages + index; per form: syntax, derived decode mask/match, an
  inline-SVG bitfield diagram (contiguous same-owner bit runs merged into
  labeled cells; fixed bits show their binary value, reserved-zero bits show
  0), notes, and the expanded mnemonic list with canonical base words from
  expand_mnemonics (1492 form mnemonics render; alias names are a listed
  real-generator item).
- Provenance-aware: only public sources (AN14650, bunny_build) render as
  citations; confidential source ids never appear in output.
- Theme-aware token CSS (light/dark via prefers-color-scheme +
  data-theme override), SVG styled through CSS classes so diagrams follow
  the theme; deterministic output.
- Spot-checked E_COND_MVNS base 0x80000200 (N bit 31 + S bit 9) correct on
  the rendered page.

Single-page preview published for review (private artifact):
https://claude.ai/code/artifact/639dfa0e-6482-46c8-8e36-c6d2df7cc95c

## Carried to build-static-html (once the ADR is accepted)

- Jinja2 + markdown enter the dev dependency group; templates replace the
  spike's f-strings (page structure and the SVG walk carry over).
- Alias mnemonics (E_POP/E_PUSH families) on their form's page.
- Prose chapters (architecture-overview, pattern-library) as Markdown with
  [[E_NAME]] cross-link resolution against the expanded mnemonic set.
- Index gains the client-side mnemonic filter; --check reproducibility mode;
  generated docs/html/ committed only together with that check.
