# Log: populate-isa-db — full population, verified against bunny_build header

ADR isa-adr-0001 accepted (decode-mask convention + mnemonic patterns folded in).
All base opcodes populated: **22 opcode files, 38 forms, 7 aliases** — every one
of the **1487** encoder functions in `include/bunny_build__instr.h` now
structurally verifies against exactly one form or alias of the db.

## New tooling (isa/tools/)

- `extract_header.py` — parses every `static inline void E_*` encoder, numerically
  probes each argument bit-by-bit (args are unmasked in the header, so probes that
  carry into base bits are treated as out-of-range and dropped), emits a JSON
  inventory: base word + per-arg value-bit→instr-bit maps.
- `verify_encodings.py` — **name-free** verification: each header fn's base must be
  exactly explained by one form's fixed+modifier bits (or an alias's baked preset),
  and each fn argument must match exactly one operand field's slices over the
  db-declared width. Also fails on ambiguous matches and dead forms. Negative-tested:
  moving the `sgn` flag by one bit produces exactly the 10 expected failures.

## Family structure discovered (all mechanically derived)

- ALU (0x06 ADD, 0x08 SUB, 0x09 ADC, 0x0a SBC, 0x0c OR, 0x0d AND, 0x0e XOR):
  identical matrix. N = **bit 19** (not 31!), F flip = bit 31, shift type [30:29],
  shift5 [28:24], IMM select bit 18 (imm12s in [31:20]).
- Shift 0x10: shift type [19:18], fused ALU op [31:29] (0=none 1=AND 2=OR 3=XOR
  4=ADD 5=SUB 6=ADC 7=SBC), amount imm [28:24].
- Flip-shift 0x11: bit 18 = FEND/FBIT, bit 19 = LSR/ASR, same fuse encoding.
- Register-shift 0x19 (480 fns): fuse op [31:29], bit 28 = pipeline order
  (op-first vs shift-first), **N = bit 27**, shift-amount register only 3 bits
  [26:24] → **R0-R7 restriction** (flag for the EZH creator).
- Loads 0x01: word bit 18, signed bit 21, wb bit 20, post bit 19; POP/POPB/POPBS
  are aliases (SP, offset -1, wb, pre-index).
- Stores 0x02: wb is **bit 10** (unused dest slot); PUSH/PUSHB aliases (SP, +1,
  wb, post).
- 0x12 is a sub-op family: [8:5] selects NOP/HEART_RYTHM/SYNCH_ALL_TO_BEAT/
  WAIT_FOR_BEAT (bit 9 splits heart imm/reg) — none are conditional; nop.toml
  extended accordingly.
- HOLD 0x1c: plain = PC baked in dest slot + bit 15; VECTORED_HOLD's table
  register is **replicated** into [13:10] and [23:20] (slice model handles it);
  ACC = bit 9, LV = 19, NRA = 18.
- 0x1d register-offset load/store: direction bit 30, offset register [27:24].
- INT_TRIGGER 0x14 (x24 in [31:8], no cond possible), TIGHT_LOOP 0x1a,
  GOSUB 0x03 (fixed [1:0] only), PER_READ 0x04.
