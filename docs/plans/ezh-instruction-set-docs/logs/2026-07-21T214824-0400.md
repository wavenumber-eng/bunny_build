# Log: verify-encodings — mnemonic expansion verified, 1502/1502

The last untested layer of the db is now mechanical: `mnemonic` pattern data,
draft until tonight, expands to **exactly the fsl header's 1502-name list with
every name's base encoding word predicted bit-for-bit** from its bound field
values. The name grammar and the bit grammar now verify each other.

## New tool: isa/tools/expand_mnemonics.py

Expands every form's pattern(s) and every alias, then checks (1) name-set
equality with the fsl inventory (extract_fsl is the ground truth), (2) no
name produced twice, (3) per-name base-word prediction vs the macro's actual
base — a pattern that spells the right names with the wrong bindings fails.
Negative-tested: swapping the rshift order guards produces exactly 448 base
mismatches; deleting the LDRBS pattern produces exactly 2 missing names.

## Notation v2 (ADR isa-adr-0001 amended 2026-07-21; README section added)

Three real grammars the original notation could not express, all additive:

- explicit alternation values — bitop's selector is sparse
  (`{BCLR=1|BTST=5|BSET=6|BTOG=7}`, field [31:29])
- `mnemonics` list + `when` guards — rshift spells order 0 as `RLSL_ADD[N][S]`
  and order 1 as `ADD[N]_RLSL[S]` (token reordering), and `_PRE`/`_POST`
  imply the writeback bit as well as post
- operand-presence splits as separate entries — `E_ADD`/`E_ADD_LSL` and
  `E_LOAD_IMM`/`E_LOAD_SIMM` share encodings, differing only by an optional
  argument

## Name-grammar facts pinned down by base verification (were draft/wrong)

- hold suffix order is `[_LV][_NRA]` (db had `[_NRA][_LV]`)
- `E_LDRS`/`E_STR_REGS` do not exist: the signed S applies to byte loads only
  (LDRBS, LDR_REGBS) — patterns split accordingly
- POST addressing names bake writeback+post; PRE bake writeback
- ALU families have plain (`E_XOR`), `_F` (flip, no shift), `_<shift>`, and
  `_F<shift>` name tiers; N spells inside (`XORN_FASRS`)
- shift/fshift fused names put the shift first (`E_ASR_XOR[S]`,
  `E_FBIT_LSR_XORS`), fuse values 1-7
- rshift order bit confirmed against names: 0 = shift-then-op spelling,
  1 = op-then-shift spelling (448-name population each way)
