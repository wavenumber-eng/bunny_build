## Conventions established this session

- Prose chapters live in `docs_src/` as Markdown with `+++` TOML front matter.
- **Provenance lives in front matter, not the body**, keyed by section anchor, so
  a confidential source id is structurally incapable of reaching a rendered page.
- Hedged claims carry `[[unverified]]` entries (claim / basis / resolve_by) AND
  inline blockquotes - visible to a reader, enumerable by tooling.
- Source authority ranking recorded in `arch.toml [sources]`: creator's spec
  outranks AN14650 for behaviour; AN remains the sole citable source. Authority
  and citability are separate axes.
- `nxp_chipdata` registered as a new public source (vendor register/pin/IRQ data).

  made a required search-index behaviour.
