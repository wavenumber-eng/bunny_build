# Log: instruction-prose — iteration three (consolidated deep review)

Four-lens external review (AN14650 fidelity, spec/flag rules, SV executable
witness, cross-file consistency) — including two corrections to the review's
own earlier findings. Everything applied; all four verifiers green.

## Review self-corrections incorporated (R1, R2)

- **GOTO window is 8MB, not 2MB** (the earlier 2MB claim conflated
  bunny_build's byte mask with the word field). The architectural immediate
  is 21 WORD bits in instr [31:11]; sv_tb computes
  (PC & 0xff800000) | (inst[31:11] << 2). goto_addr21 widened to the
  architectural width (value 22:2 -> instr 31:11) — verification-compatible,
  and verify_fsl passing on the widened field proves the fsl macros populate
  the full width; only bunny_build's '& 0x1FFFFF' clamps to the low 2MB.
  Recorded as an **assembler improvement opportunity**, not just a doc note.
- **GOTO RA rules restated referent-free** — AN14650 5.22's PC-4/PC+4
  spellings are internally swapped against its own descriptive sentence
  (defect candidate #5; sv_tb agrees with the description): scheduled ->
  RA = GOTO+12, ordinary -> RA = GOTO+4. gosub.toml now states RA = the
  word after the GOSUB (sv_tb, advisory).

## Majors fixed (M1-M7)

- M1 **PC-write scheduling inversion** (9 files + arch.toml): plain PC write
  = ordinary 3-cycle branch; S + PC destination = scheduled. Triple-sourced
  (spec worked examples, SV write_that_reg sflag argument, AN14650 5.1).
- M2 **Verbatim spec run removed** from tight_loop.toml (the one 10-word hit
  from the review's 8-gram scan; everything else scanned clean).
- M3 **shift/fshift operand order**: the shifted value is the LEFT operand
  (dest = shifted OP Roperand) — matters for SUB/SBC; both files explicit.
- M4 **Condition codes**: AZ = Above Zero (ARM GT); CZ = Carry set AND zero
  (spec wording); SPO/SNE rewritten as the algorithmic shift-only
  conditions with their GOTO meanings (UNS unconditionally scheduled, NZS
  scheduled-iff-NZ).
- M5 **Carry rule stated**: only ADD/SUB/ADC/SBC and shift/rotate stages can
  change C; logical ops and MOV retain it even with S — in the s field desc
  and the and/or/xor/mov/bitop proses.
- M6 **Byte-stacking restriction** (AN14650 5.29) added to both PUSH/POP
  carriers.
- M7 offset8s is access-size-scaled (was "byte offset" — 4x error for word
  access); ldr/mem_reg syntax no longer advertises nonexistent
  E_LDRS/E_LDR_REGS; lv desc corrected to Large Vector.
