# Log: platform-discovery-parser-selftest

Follow-up to the clean review of `5d1bc3a`.

The review left one residual regression risk: the new parser edge cases were
covered by manual probes, but not by committed tests. `discover_parts.py` now
has an offline parser self-test that covers:

- zero-count `FSL_FEATURE_SOC_SMARTDMA_COUNT`
- zero-count and positive `FSL_FEATURE_SOC_EZH*_COUNT`
- implicit, explicit-zero, and parenthesized-zero `EZH_ARCH_B`
- uncommented RT-style `SDMA_IRQn`
- comment-driven SmartDMA IRQ matching for `/**< ... */` and `/*!< ... */`
- EZH common-header IRQ matching

The self-test is available directly via
`uv run python isa/tools/discover_parts.py --self-test` and is also run before
the normal discovery/check paths.
