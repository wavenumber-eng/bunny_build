# Log: static-html-published

Landed the generated static HTML artifact as a reproducible repo output.

The publication gate now consists of:

- `isa/tools/gen_docs.py --check`, which runs the ISA verifier suite, chapter
  linter, generated-output public scan, and byte comparison against `docs/html/`
- the `.ezh-docs-generated` sentinel in `docs/html/`
- `isa/tools/check_public_docs.py`, including review-process marker coverage for
  creator-confirmation, hardware-analysis, advisory, and adjudication wording
- generated search over chapters, opcode panels, mnemonics, registers,
  conditions, and fields via vendored MiniSearch 7.2.0

The committed tree contains the generated pages, search index, and vendored
browser search asset. Platform and simulator pages remain placeholders for their
own later plan steps.
