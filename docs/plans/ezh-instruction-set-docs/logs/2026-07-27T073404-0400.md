# Log: build-static-html

Implemented the deterministic static HTML generator and committed-output check.

## Deliverable

`isa/tools/gen_docs.py` now renders `docs/html/` from `isa/ezh_b/*.toml`,
`docs_src/*.md`, Jinja2 templates, and an inlined stylesheet. The generated site
contains:

- `index.html`
- `architecture.html`
- `assembler.html`
- `cookbook.html`
- `instructions.html`
- `platform.html` placeholder
- `simulator.html` placeholder
- `search_index.js`
- vendored MiniSearch 7.2.0 browser asset, license, and package metadata

The instruction reference is one page with one expandable panel per base opcode.
Each panel renders semantics, restrictions, public provenance, forms, decode
mask/match, bitfield SVGs, generated mnemonic tables, and alias tables.

## Search

Search is local and offline. The generator emits a deterministic
`search_index.js` asset covering chapters, chapter sections, opcode panels, and
mnemonics. The site loads vendored MiniSearch and performs exact/prefix mnemonic
hits before ranked full-text results. EZH/SmartDMA and Arm/host terms are
expanded as search aliases.

## Confidentiality gates

The chapter linter now treats non-public marker hits as hard failures in body
text and renderable provenance detail. `isa/tools/check_public_docs.py` scans the
rendered artifact for non-public source ids, private source titles/aliases,
private filenames, and confidential banners. The first generator run caught real
public-output leaks in search data and opcode provenance; those source strings
were rewritten to keep the behavior while removing private-source framing.
A follow-up review added the same hard-fail treatment for review-process terms
such as hardware-analysis/advisory/adjudication wording, then rewrote the
renderable opcode prose that had used those labels.

## Verification

`uv run python isa/tools/gen_docs.py --check` passes. The check runs:

- `isa/tools/validate.py`
- `isa/tools/expand_mnemonics.py`
- `isa/tools/verify_encodings.py`
- `isa/tools/verify_fsl.py`
- `isa/tools/lint_chapter.py docs_src/architecture.md docs_src/assembler.md docs_src/cookbook.md --quiet`
- `isa/tools/check_public_docs.py` on a temporary generated tree
- byte comparison of the temporary generated tree against committed `docs/html/`

Result: 25 opcodes, 1502 mnemonics, 3 prose chapters, and 150 search documents.
