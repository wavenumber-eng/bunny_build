# Log: cookbook-rare-branch-patterns

Executor-side cookbook audit pass after moving forward on `pattern-library`.

The sample-mining log called out two rare `EZH_ConditionFlag` idioms that the
cookbook draft did not yet carry:

- using `E_COND_GOTO(UNS)` as a scheduled branch and putting mutually exclusive
  `E_COND_PUSH(EX)` / `E_COND_PUSH(NEX)` work in the two shadow slots;
- read-modify-writing `EZH_CTRL` with the `0xC0DE` key so EZH updates the
  external flag it later tests with `EX`/`NEX`.

Changes:

- Added cookbook section `Use branch shadows deliberately`.
- Added provenance for the feature-demo source evidence.
- Fixed the architecture chapter's stale contradiction that said EZH could only
  observe `EXF`; the chapter now says the Arm usually owns the flag, but EZH can
  update the writable control register through an ordinary keyed write.

The cookbook remains pending Eli's personal pattern/content audit.
