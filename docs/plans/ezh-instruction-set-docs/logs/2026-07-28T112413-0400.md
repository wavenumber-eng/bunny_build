# Log: e-end-single-spelling

Supersedes the previous two-spelling park helper fix.

Decision: use one public and implementation spelling, `E_END()`, matching the
single-underscore `E_*` helper style used elsewhere in bunny_build.

Changes:

- Removed the `E__END()` declaration from the public pseudo-instruction header.
- Renamed the implementation body to `E_END()` instead of wrapping the old
  double-underscore spelling.
- Reduced the host link probe to `E_END()` only.
- Updated assembler/cookbook source to present `E_END()` as the single
  command/execute/IRQ/park helper.

Older corpus notes can still cite historical local helpers when reviewing source
evidence, but generated guidance should not teach two callable names for the same
park pattern.
